# Face au Client IA

Application pédagogique de simulation de relation client avec IA locale gratuite.

## Utilisation
- Ouvrir l'application via GitHub Pages
- Utiliser Chrome ou Edge récent
- Cliquer sur **Charger l'IA**
- Aucun compte IA, aucune clé API, aucun paiement

## GitHub Pages
Dans **Settings > Pages** :
- Source : Deploy from a branch
- Branch : main
- Folder : / (root)
